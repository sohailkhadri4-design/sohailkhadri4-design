## Featured Embedded Projects

### 1. STM32 Sensor Monitoring & Communication Firmware

Embedded C firmware for an STM32 ARM Cortex-M microcontroller that interfaces with sensors over I2C and SPI, reports data over UART, and handles GPIO-based status/control.

**Tech:** `Embedded C` `STM32` `ARM Cortex-M` `I2C` `SPI` `UART` `STM32 HAL`

🔗 [View repository](https://github.com/sohailkhadri4-design/stm32-sensor-monitoring-firmware)

### 2. Robotic System Testing & Fault Detection Framework

Python-based testing framework for embedded robotic systems covering sensor validation, motor-command validation, fault classification, logging, integration tests, and automated CI testing.

**Tech:** `Python` `pytest` `Test Automation` `Sensors` `Motor Control` `Fault Detection` `GitHub Actions`

🔗 [View repository](https://github.com/sohailkhadri4-design/Robotic-System-Testing-Fault-Detection-Framework)

### 3. Sensor-Based Distance Measurement System

Raspberry Pi and HC-SR04 ultrasonic distance measurement system with GPIO timing, timeout handling, distance processing, validation, simulated hardware interfaces, and automated tests.

**Tech:** `Python` `Raspberry Pi` `GPIO` `HC-SR04` `Sensors` `pytest`

🔗 [View repository](https://github.com/sohailkhadri4-design/Sensor-Based-Distance-Measurement-System)

### 4. IoT Smart Irrigation System

ESP32-based irrigation control system that reads soil moisture, converts ADC measurements into moisture percentage, applies hysteresis-based watering control, and drives a relay-controlled pump.

Includes Arduino/PlatformIO reference firmware, sensor-fault handling, UART telemetry, documentation, and CI build configuration.

**Tech:** `ESP32` `Arduino` `PlatformIO` `C++` `ADC` `Soil Moisture Sensor` `Relay` `IoT`

🔗 [View repository](https://github.com/sohailkhadri4-design/IoT-Smart-Irrigation-System)

### 5. Autonomous Robot Control System

Real-time robot control software implementing five motor-control states: idle, forward, reverse, left turn, and right turn. The project separates control logic, GPIO interfaces, and motor-control hardware and includes simulated GPIO testing.

**Tech:** `Python` `Raspberry Pi` `GPIO` `Motor Control` `State Machine` `Real-Time Control`

🔗 [View repository](https://github.com/sohailkhadri4-design/Autonomous-Robot-Control-System-)
