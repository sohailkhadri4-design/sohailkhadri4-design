## Featured Projects

### 1. STM32 Sensor Monitoring & Communication Firmware

Reference STM32F401RE firmware implementation in Embedded C using STM32 HAL. Interfaces a BME280 over I2C and MAX6675 over SPI, reports diagnostics through UART, controls GPIO status indication, and separates sensor communication from fault handling.

**Tech:** `Embedded C` `STM32F401RE` `ARM Cortex-M4` `STM32 HAL` `I2C` `SPI` `UART` `GPIO`

**Verification status:** Firmware reference implementation with a documented verification plan. Physical hardware results are not claimed.

🔗 [View repository](https://github.com/sohailkhadri4-design/stm32-sensor-monitoring-firmware)

### 2. Robotic System Testing & Fault Detection Framework

Python reference framework for software-level testing of robotic subsystems. Validates sensor readings and motor commands, injects repeatable fault conditions, classifies failures, records structured logs, and runs automated pytest checks through GitHub Actions.

**Tech:** `Python` `pytest` `Fault Injection` `Test Automation` `Sensors` `Motor Control` `GitHub Actions`

**Verification status:** Automated software tests use deterministic simulated interfaces. Physical robot test results are not claimed.

🔗 [View repository](https://github.com/sohailkhadri4-design/Robotic-System-Testing-Fault-Detection-Framework)

### 3. Autonomous Robot Control System

Real-time robot control software implementing five operating states: idle, forward, reverse, left turn, and right turn. Separates state-machine logic, GPIO interfaces, and motor-control commands and includes simulated GPIO testing.

**Tech:** `Python` `Raspberry Pi` `GPIO` `Motor Control` `State Machine`

🔗 [View repository](https://github.com/sohailkhadri4-design/Autonomous-Robot-Control-System-)

### 4. Sensor-Based Distance Measurement System

Raspberry Pi and HC-SR04 reference application implementing trigger/echo timing, timeout handling, distance conversion, range validation, moving-average processing, and simulated GPIO testing.

**Tech:** `Python` `Raspberry Pi` `GPIO` `HC-SR04` `pytest`

🔗 [View repository](https://github.com/sohailkhadri4-design/Sensor-Based-Distance-Measurement-System)

### 5. IoT Smart Irrigation System

ESP32/Arduino reference firmware for soil-moisture monitoring and relay-controlled irrigation. Converts ADC readings to moisture percentage, applies hysteresis-based control, reports telemetry over UART, and handles sensor-fault states.

**Tech:** `ESP32` `C++` `Arduino` `PlatformIO` `ADC` `Relay Control` `IoT`

🔗 [View repository](https://github.com/sohailkhadri4-design/IoT-Smart-Irrigation-System)
